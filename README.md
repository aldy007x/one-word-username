This entry is a single word: the entrant's own make.fun username, `aldy007x`.
The program writes exactly that word — eight characters, no spaces, no extra
lines — to `entry.txt`, then reads it back and verifies it against the
bounty's gate (one non-blank line, 1–30 characters) before exiting.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/path/to/output python3 main.py
```
